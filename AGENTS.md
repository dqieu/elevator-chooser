# Development

`dist/` is editable source, not disposable build output. Keep formulas and engineering inputs distinct from reference drawing graphics. Do not add original workbooks/DWGs, passwords or private analysis to Git. Run `npm test` and `npm run check` for changes. CAD changes also require visual comparison and, where available, ODA readback. Record deviations from the reference in CHANGELOG.md; do not claim model suitability from a drawing resemblance.
